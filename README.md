# SubwaySurfers – Lernkarten Web App

Dieses Projekt ist eine Webanwendung zum Lernen mit digitalen Karteikarten.  
Die Anwendung ermöglicht es, Lernsets zu verwalten und im Lernmodus zu wiederholen.

---

## Funktionen

- Anzeige verschiedener Lernsets
- Lernmodus zum Wiederholen von Karten
- Bearbeiten von Lernsets
- Karteikasten-System

---

## Technologien

- Next.js
- React
- TypeScript
- CSS Modules

---

## Projekt starten

### 1. Repository klonen

- ```git clone https://github.com/anne-kmmr/SubwaySurfers.git```

### 2. In den Projektordner wechseln

- ```cd SubwaySurfers```

### 3. Abhängigkeiten installieren

- ```npm install```

### 4. Development Server starten

- ```npm run dev```

Danach im Browser öffnen:

- http://localhost:3000
